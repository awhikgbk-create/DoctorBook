DoctorBook - النسخة المتكاملة الأساسية (MVP)

المتطلبات:
- Visual Studio 2022.
- .NET 8 SDK.
- SQL Server LocalDB (أو SQL Server وتعديل Connection String).

التشغيل:
1) فك ضغط DoctorBook_Full.zip.
2) افتح DoctorBook.csproj في Visual Studio.
3) انتظر استعادة NuGet Packages.
4) اضغط F5 أو شغّل من Visual Studio.

حساب الإدارة:
- افتح appsettings.json.
- اكتب بريد الإدارة في SeedAdmin:Email وكلمة مرور قوية في SeedAdmin:Password.
- شغّل المشروع. سيتم إنشاء حساب الإدارة وإضافته إلى دور Admin تلقائيًا.
- بعد أول تشغيل، لا تترك كلمة المرور في ملف الإعدادات عند النشر. استخدم User Secrets أو متغيرات البيئة، وغيّر كلمة المرور.

الموجود:
- حسابات مرضى ودكاترة مع أدوار منفصلة.
- تسجيل الطبيب ينتج ملفًا غير معتمد حتى توافق الإدارة.
- صفحات بحث وملف عام لكل طبيب على /doctors/{id}.
- لوحة الطبيب: تعديل الملف، إضافة جدول العمل، إدارة الطلبات وتغيير حالتها.
- لوحة الإدارة: اعتماد الأطباء، متابعة الحجوزات وتسجيل الدفع النقدي.
- حجز المريض، إلغاء الطلب المعلق، منع تكرار نفس الموعد.
- إشعارات داخل الموقع.
- سجل دفع مبدئي نقدًا في العيادة.

حدود النسخة:
- لا يوجد تحصيل إلكتروني حقيقي. تكامل بوابة دفع يحتاج حساب تاجر ومفاتيح سرية من مزود دفع (مثل Paymob أو Stripe حسب البلد).
- لا يوجد إرسال SMS أو بريد فعلي؛ الإشعارات داخل الموقع فقط. ربط مزود الرسائل/البريد يحتاج مفاتيح وحسابات.
- لا يوجد نظام طبي للسجلات أو الوصفات أو التشخيص، ولا ينبغي استخدام الموقع لتخزين بيانات طبية حساسة قبل مراجعة أمنية وقانونية متخصصة.
- لا تزال هناك حاجة لاختبارات شاملة، migrations، سياسة خصوصية وشروط استخدام، نسخ احتياطي، HTTPS وإعداد استضافة قبل الإطلاق العام.

تنبيه قاعدة البيانات:
هذه الحزمة تستخدم EnsureCreated لتسهيل أول تشغيل. عند بدء تطوير فعلي مستمر، انتقل إلى EF Core Migrations قبل نشرها أو تحديث قاعدة البيانات.
